Device configuration for Motorola G57 Power and Motorola G100S (china)
=========================================

> **VoltageOS 17 port.** Build and flash instructions: [voltage/BUILDING.md](voltage/BUILDING.md)

The Motorola G57 Power and Motorola G100S(CN) (codenamed _"mumba"_) are mid-range smartphone from Motorola announced and released in December 2025.

## Device specifications

| Basic                   |  Spec Sheet                                                  |
| ----------------------- | :----------------------------------------------------------- |
| SoC                     | Qualcomm Snapdragon 6s Gen 4 (SM6435-AA)                     |
| CPU                     | Octa-core (4x2.4 GHz Cortex-A78 & 4x1.8 GHz Cortex-A55)      |
| GPU                     | Adreno 710                                                   |
| Memory                  | 8GB / 12GB RAM (LPDDR4X)                                     |
| Shipped Software        | Android 16, HelloUI                                                           |
| Storage                 | 128 GB / 256 GB UFS (2.2)                                    |
| Battery                 | Non-removable Si/C Li-Ion 7000 mAh                           |
| Dimensions              | 166.2 x 76.5 x 8.6 mm (6.54 x 3.01 x 0.34 in)                |
| Display                 | 1080 × 2400 (20:9) 6.72-inch FHD+ IPS LCD, 120 Hz,           |
| Rear camera             | 50 MP, f/1.8 (wide), 1/1.95", 0.8µm, PDAF,8 MP, f/2.2, 120˚ (ultrawide), 1/4.0", 1.12µm                   |
| Front camera            | 8 MP, f/2.2, (wide), 1/4.0", 1.12µm, HDR,                                                  |
